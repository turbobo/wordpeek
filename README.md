# 瞄词 WordPeek

> 打字时，在你刚输入的词旁瞄一眼它的英文。

**不换输入法、不装插件、不改配置。** 系统拼音、搜狗、微信输入法——你原本用什么就用什么：在任何应用里打中文，词上屏的瞬间，光标旁弹出一个小浮窗显示英文（`打工人 → worker · office worker`），看一眼就走，不打断输入。

## 为什么是「瞄词」

同类「打字学英语」开源工具几乎都是**输入法形态**（Rime 插件、自定义输入法等）：必须先安装并切换到它们才能用。瞄词是**独立形态**——通过 macOS 辅助功能 API 监听输入内容，与输入法完全解耦：

| 对比项 | 输入法形态（同类工具） | 瞄词 WordPeek |
|---|---|---|
| 安装方式 | 安装输入法框架 / 插件 + 改配置 + 重启 | 下载 `.app` → 授权 → 完成 |
| 输入法要求 | 必须改用指定输入法 | **任何输入法通用**（系统拼音 / 搜狗 / 微信…） |
| 生效场景 | 仅该输入法内 | 所有应用的任意输入框 |
| 英文出现时机 | 候选框内（选词阶段可见） | 上屏瞬间（光标旁浮窗） |
| 打字习惯 | 需要改变 | **零改变** |

> 说明：候选阶段显示是「输入法形态」的天然优势（需输入法自身可扩展）；瞄词选择「零门槛通用」路线，在词上屏的瞬间展示。

## 特性

- **任何输入法通用**：系统拼音 / 搜狗 / 微信输入法……打中文即触发，无需切换输入法、无需安装插件
- **任何应用生效**：微信、浏览器、备忘录、编辑器——光标在哪，浮窗就在哪
- **纯本地**：差分与查词都在本机内存完成，不联网、不上传（唯一联网行为是下载词典）
- **离线词典**：内置演示词表开箱即用；一键下载 CC-CEDICT 完整词典（约 12 万词条，CC BY-SA 4.0）
- **不打扰**：非激活浮窗，不抢焦点、不接收鼠标；同词 3 秒冷却；高频功能词与单字默认不弹
- **可控**：菜单栏一键暂停/启用；浮窗时长可调；可选展示单字词
- **隐私安全**：自动跳过密码框（AXSecureTextField）；粘贴长文本/混合内容不触发

## 快速开始

```bash
# 构建（需 Xcode 与 xcodegen）
./scripts/build.sh

# 运行
open dist/WordPeek.app
```

首次启动：

1. 弹出引导窗口 → 点「打开系统设置」授权**辅助功能**权限
   （系统设置 → 隐私与安全性 → 辅助功能 → 勾选「瞄词」）
2. 在「试一试」输入框直接打字体验完整效果（此步无需任何权限）
3. 点「下载完整词典」扩展词库（约 10MB，离线可用）

## 打字不弹翻译？（30 秒自查）

```bash
./scripts/doctor.sh      # 重启应用并实时输出全链路诊断日志
```

日志会直接指出断在哪一层（日志同时落盘 `/tmp/wordpeek-debug.log`）：

| 诊断输出 | 含义 | 怎么办 |
|----------|------|--------|
| `辅助功能授权 = 未授权` / `poll AX 未授权` | **最常见**：ad-hoc 重签名后 TCC 授权失效（权限绑定签名指纹） | 系统设置 → 隐私与安全性 → 辅助功能 → 先移除「瞄词」→ 重新勾选；或先执行 `tccutil reset Accessibility app.wordpeek.mac` |
| `poll 焦点元素非文本输入类，忽略 role=AXUnknown` | 该应用的输入框不暴露 Accessibility 信息（部分密码管理器 / 加固应用） | 换 TextEdit / 备忘录验证；属预期不监听 |
| `poll 读不到 AXValue` | 应用不支持读取文本值 | 同上，属预期 |
| 有 `ingest external len=…` 但没有 `present word=…` | 差分出的片段被阀门过滤（>16 字视为粘贴 / 含非汉字 / 停用词 / 词典无此词） | 在设置里打开「显示单字词的英文」，或下载完整词典 |
| 有 `present word=…` 但没有 `overlay show` | 浮窗展示异常 | 反馈日志 |
| `overlay show … visible=false` | 浮窗被系统或全屏空间遮挡 | 检查显示器 / 换个应用 |

界面上也有同等信息：**菜单栏图标**变橙色感叹号 = 未授权（菜单第一行可直接点击去授权）；
**设置窗口「1 · 辅助功能权限」下的「诊断」行** = 轮询器的实时结论。

## 开发

```bash
./scripts/test.sh    # 单元测试（41 个用例，headless 直跑）
./scripts/doctor.sh  # 全链路诊断（定位「打字不弹」）
```

- `WordPeekCore/`：纯逻辑 framework（文本 diff / 词典 / 切词 / 查词管线），不依赖 AppKit，可单测
- `WordPeek/`：App 层（Accessibility 监听 / 浮窗 / 设置窗口 / 菜单栏）
- 工程由 `project.yml`（xcodegen）声明式生成，`WordPeek.xcodeproj` 为构建产物（已 gitignore）

## 权限与原理

- 监听原理：Accessibility API 以 0.25s 轮询系统焦点输入框的文本快照，在本地做字符级差分，
  提取「刚上屏的词」→ 查词典 → 浮窗展示
- 为什么需要「辅助功能」权限：这是 macOS 读取其他应用输入内容的唯一合法通道
- 词典数据：CC-CEDICT（CC BY-SA 4.0），https://cc-cedict.org

## 已知限制

- 只能拿到「上屏后」的词；想在输入法**候选框内**直接看英文，需要输入法自身可扩展（如 Rime 生态）
- ad-hoc 签名：每次重新构建后**必须**在「系统设置 → 隐私与安全性 → 辅助功能」中
  移除旧记录后重新勾选，否则表现为「打字不弹翻译」（构建脚本会提示；
  未授权时应用每次启动都会自动唤出引导窗口）
- 极少数禁用 Accessibility 的应用（如部分密码管理器内部）不会被监听（符合预期）
